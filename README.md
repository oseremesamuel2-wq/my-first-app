My First React App

A simple interactive React application built with React and Vite as part of my frontend development training.

Features

- Displays a personal introduction
- Interactive counter
- Increase, decrease, and reset buttons
- Displays whether the counter value is even or odd
- Name input with a personalized greeting
- Conditional rendering
- Current year displayed in the footer

Technologies Used

- React
- Vite
- JavaScript
- CSS
- JSX

How to Run Locally

1. Clone the repository:

git clone YOUR_REPOSITORY_URL

2. Enter the project folder:

cd my-first-app

3. Install dependencies:

npm install

4. Start the development server:

npm run dev

5. Open the local URL provided by Vite in your browser.

Assignment

This project was created to practise React fundamentals including functional components, JSX, state management with "useState", event handling, and conditional rendering.
